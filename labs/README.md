# 🧪 Hands-on Labs

[← Back to Ollama AI Industry Use Cases](../README.md)

Labs are longer, guided exercises that teach one AI engineering idea step by step. They're different from the
use cases in the industry folders:

| | Use cases (`01_banking/`, `02_retail/`, ...) | Labs (`labs/`) |
|---|---|---|
| Shape | One `app.py` per business problem | Several modules you run in order |
| Goal | Show an AI solution to a business problem | Teach *why* a technique works, with a before/after score |
| LLM | Local, via Ollama | Whatever the lab's platform provides (stated in each lab) |
